## 📖 Project Overview
This project is a modren responsive single page web application designed to deliver an intituative user experience across desktop, tablets and mobile devices. It showcase core front-end skills including semanic HTML structuring, modren CSS layouts(Flexbox & Grid), Media quries and dynamic DOM manipulation with JavaScript.

## ✨ Key Features

- **Responsive Design:** Optimized for seamless viewing on all device sizes using custom media queries.
- **Semantic HTML5:** Built using clean, accessible and structured markup.
- **Modren Styling:** Styled using custom CSS variables, Box Model standards, and layout modules.
- **Interactive JavaScript:** Features dynamic elements powered by JavaScript functions, arrays, objects,eventlistners, and DOM manipulation.
- **Cross Browser Compatibility:** Tested and verified across major desktop and mobile browsers.
